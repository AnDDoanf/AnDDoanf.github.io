# Drum sample kits

The Acoustic, Electronic and Lo-fi kits are built from samples in the [Phazite Sounds pack](https://github.com/august-byrne/phazite-sounds), released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The upstream pack includes `pack/sources.json` with per-file provenance, source links, and processing notes.

The **GrooveScribe** kit is copied from [montulli/GrooveScribe](https://github.com/montulli/GrooveScribe/tree/master/soundfont/NewDrumSamples/MP3) with the user's authorization. This includes the complete MP3 set from that directory. GrooveScribe's source repository is GPL-2.0; see [its license](https://github.com/montulli/GrooveScribe/blob/master/LICENSE.txt). The kit is kept in its own folder and its recordings are used unchanged.

| Kit | Included sounds | Provenance |
| --- | --- | --- |
| Acoustic | Kick, snare, closed/open hi-hat, high/low/floor tom, crash, ride | Virtuosity Drums (Versilian Studios / Karoryfer Samples), VCSL, Big Rusty Drums (Karoryfer Samples) |
| Electronic | Kick, snare, closed/open hi-hat | FreePats Synthesizer Percussion; analog hats synthesized by Phazite |
| Lo-fi | Soft kick, electronic snare, tight closed hat, floor tom | Sonic Pi / Freesound (kick), FreePats, VCSL, Big Rusty Drums |
| GrooveScribe | Complete upstream MP3 set, including snare articulations, hi-hat variants, toms, cymbals, bells and metronome sounds | GrooveScribe repository, included under user authorization |

Each bundled file was downloaded from the upstream pack's `pack/Drums/` directory and converted from FLAC to MP3 for browser compatibility. The upstream source record documents the component source and CC0 evidence. The original pack-level license is included as `LICENSE-CC0.txt`.

Source: https://github.com/august-byrne/phazite-sounds/blob/main/pack/sources.json
