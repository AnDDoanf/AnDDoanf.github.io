## Project Overview

**Aurora PSS Analytics** is a feature-rich client application built for Pixel Starships players. It serves as an exploration library and strategic planning tool, featuring crew statistics, training logs, inventory optimization, and a dynamic ship builder.

## Key Features

### 🚀 Interactive Ship Builder
An interactive drag-and-drop workspace that lets players build and test room configurations, power grids, and defense layouts.

### 📊 Training & Crew Analytics
Tools for calculating training gains, optimal paths, and inventory layouts to maximize crew stats.

### 🕵️ Player & Fleet Intelligence
Ingests API data to search players, audit fleets, track history, and check statistics.

### 🌐 Multi-Language Interface
Supports localized terms for various languages to match in-game terminology.

## Technology Stack

- **Frontend**: React, Vite, Tailwind CSS.
- **Data Ingestion**: Node.js scripts for parsing Pixel Starships API responses.
- **Cache**: LocalStorage state preservation.
